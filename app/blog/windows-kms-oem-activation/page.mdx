Ever found yourself stuck needing to switch your Windows edition—like upgrading from Home to Pro—or doing a clean setup on a fresh PC, but you don't have your actual product key handy? Don't sweat it!

Microsoft actually provides official generic product keys (aka default keys). Think of these like universal placeholder keys. They let you select, install, or switch your Windows edition free of charge and completely legally.

> **Heads up though: These keys won't give you a free permanent activation. They just let you install the OS, switch editions, or bypass the key setup screen so you can activate it properly later with your real license!**

## The Official Generic Key

| Target Edition | Generic Product Key |
| --- | --- |
| Windows 10/11 Pro | VK7JG-NPHTM-C97JM-9MPGT-3V66T |
| Windows 10/11 Home | YTMNT-PQB86-MS848-WX58X-ZGJR7 |
| Windows 10/11 Enterprise | XGVPP-NMH47-7TTHJ-W3FW7-8HV2C |

Upgrading your edition: Head over to *Settings > System > Activation > Change Product Key*, paste the generic key for your target edition, and hit start. Windows will download the extra features and switch editions right away!
